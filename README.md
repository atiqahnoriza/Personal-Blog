# Atiqah Personal Blog

Welcome to **Atiqah Personal Blog**, a personal portfolio website created by **Nurul Atiqah Binti Noriza**. This website shares my learning journey as a Computer Science student specializing in Software Development.

The website includes information about my academic background, study journey, projects, skills, goals, and contact information. It was developed using basic web technologies to demonstrate my understanding of website structure, styling, and simple interactivity.

## Live Website

[Visit My Personal Blog](https://atiqahnoriza.github.io/Personal-Blog/)

## Project Description

This project is a personal blog and portfolio website. It is designed to introduce myself, showcase my academic journey, display projects I have developed, and provide ways for visitors to contact me.

The website contains four main pages:

* `index.html`
* `about.html`
* `blog.html`
* `contact.html`

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages

## Features

* Simple and clean personal blog design
* Navigation bar for all pages
* Home page introduction
* About page with study journey and CGPA/PNGK
* Blog page displaying project portfolio
* Contact page with Email, GitHub, and LinkedIn links
* Responsive layout
* Basic animation and interactivity using JavaScript

* A hero section introducing Nurul Atiqah as a Computer Science student

The purpose of this page is to welcome visitors and give a brief introduction to the website. It acts as the starting point for users to explore other pages such as About, Blog, and Contact.

### 3. Blog / Projects Page: blog.html

The `blog.html` file is used to display projects developed during the study journey. This page acts as the project portfolio section of the website.

#### Content of blog.html

The Blog page includes:

* A navigation bar
* A hero section titled “My Projects”
* A short introduction about project development experience
* Project cards with images, project titles, and descriptions
* A section about what was learned from the projects
* A section listing tools and technologies used
* A section about future improvements

#### Projects Included

1. **Recyclable Waste Classification App**
   A mobile application integrated with YOLO object detection to classify recyclable and non-recyclable waste. This project helps users identify recyclable materials more efficiently while supporting environmental awareness.

2. **SBS Sports Booking System**
   A website that allows users to book sports facilities easily. Users can choose venues, check available schedules, view opening days and operating hours, and purchase sports equipment such as balls, rackets, and other items.
